# دفتر الوصولات

أبلكيشن أندرويد بسيط: تصوّر الوصل، تكتب وصف وتاريخ، وتدوّر عليه بعد كده.
الوصولات بتتخزن على الموبايل نفسه، وفيه زرار نسخة احتياطية واسترجاع جوه الأبلكيشن.

## بناء الـ APK على GitHub

1. اعمل Repository جديد على GitHub وارفع عليه محتويات المجلد ده كلها (مع مجلد `.github`).
2. افتح تبويب **Actions** واختار **Build APK** ثم **Run workflow**. (بيشتغل لوحده كمان مع أي push على main.)
3. استنى حوالي 5 دقايق، ادخل على التشغيل اللي خلص واسحب لتحت لحد **Artifacts**.
4. نزّل `receipts-apk`، فك الضغط، هتلاقي `app-debug.apk`.
5. انقله للموبايل وثبّته. لو ظهرت رسالة، فعّل «السماح بتثبيت التطبيقات من مصدر غير معروف».

## ملاحظات

- الـ APK ده نسخة debug للاستخدام الشخصي، مش للرفع على Google Play.
- الوصولات على الموبايل بس. لو مسحت الأبلكيشن أو بياناته هتضيع، فاعمل «حفظ نسخة احتياطية» كل فترة وخلّي الملف على Drive أو الإيميل.
- أول مرة تدوس «صوّر وصل» الأندرويد هيطلب إذن الكاميرا.
- الخطوط بتتحمل من النت. من غير نت بيستخدم خط النظام والأبلكيشن شغال عادي.

## تشغيل محلي (اختياري)

```bash
npm install
npx cap add android
npx cap sync android
npx cap open android   # يفتح Android Studio
```
